For DEV-ZERO, REBUY-ANCHOR, SEAT-DRIFT and F1 it does not say: which flow is "payer-attributed" (the row's own net, first-time buyers only, or all buyers), which window is the "hold window" (the row's flow window?), which Q (each event's own effective quote, or U1's 419 SOL), and which cost c (the $5 round trip, 2.89%?). Until these are ruled, the code reports the bar as not computed and no row or gate passes.
