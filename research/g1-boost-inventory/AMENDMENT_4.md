# G1, amendment 4: count gates over the Step A days (lead ruling, 2026-10-08)

Ruling on research/g1-boost-inventory/tape/OPEN_QUESTIONS.md OQ-27 (amendment 1 (c) and amendment 2 (d) say "a day"):

A count gate passes only if:
- the pooled Step A count reaches the frozen threshold; and
- each Step A day's own count reaches at least 40% of that threshold, so that one day cannot carry the gate.

This replaces the per-day minimum the code used pending the ruling.
