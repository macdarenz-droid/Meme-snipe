**RT-02 · MINOR · One placement test passes even if the code it checks is missing.**
- The placement test (`host-logic.test.ts`, the "reads only the host" case) uses `if (i >= 0)`.
- So any marker that is not in the built file is skipped. `# @@FILES@@` already appears 0 times in `ops/install.sh`, so that check never runs.
- **Fix:** `expect(i).toBeGreaterThan(at)` for every marker, and drop `# @@FILES@@` or replace it with a marker that exists (for example `say "Files"`).

- I believe hosted runners have a root disk of about 70 GB or more, but I have not verified that, and the `e2e` job had not finished.

## Checks that found nothing

1. **Wrongly refusing the owner's server:**
   - **Crash-dump memory (crashkernel):** Ubuntu's official kdump page says kdump is turned on by default only from 24.10, and "on pre-24.10 releases" it is enabled by hand ([Ubuntu Server docs](https://documentation.ubuntu.com/server/how-to/software/kernel-crash-dump/)). I only saw this line in a search result; the full page would not load (503).
   - **If kdump were on anyway:** a typical 2 GB VM reports about 2,014,000 kB (the test's own example). Taking off 320 MB would leave about 1.61 GiB, still above 1.5 GiB. The 320 MB figure is from memory and not verified, and the real `MemTotal` is not measured.
   - **Disk:** `df -P` keeps each line from wrapping, and the block reads the size column, not free space. A 55 GB disk should land around 53–54 GB after partitions and ext4 overhead. That is my estimate, not a measurement.
   - **Comma locales:** the comparison is plain integer math, so a comma locale can only change how the message prints, never the decision.
   - **Missing `/var/lib`:** the size can't be read, so the install refuses safely.
