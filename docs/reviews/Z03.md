### Supervisor rulings for round 2 (8 Oct 2026, 8:03 PM)

1. **MAJOR, Retry-After.** Accept only delta-seconds (a non-negative integer) or an IMF-fixdate (RFC 9110). Anything else counts as absent. The pause is `max(retryAfter, BASE × 2^(n−1))`, under the existing cap, so junk or a past date never gives a zero pause. Tests: `0`, a past date, `-5`, `1.5`, `garbage 7`.
2. **MAJOR, event trailing bytes.** Bytes left after the pinned event layout set a `layout_extended` flag and a counter, as accounts already do; such an event is never silently clean. VERIFY the 8 extra bytes on mainnet TradeEvents against the official IDL source the pinned IDLs already cite, and record the source. A newer IDL is pinned only in its own reviewed change. Test: 40 junk bytes appended are flagged.
3. **MAJOR, quote units.** A Lamports value comes only from a SOL quote: the TradeEvent's quote mint is native SOL, or the PumpSwap pool's quote mint, read from the pool account, is wSOL. Any other quote is refused (fail closed) until VERIFY settles what `sol_amount` holds on a non-SOL curve. Test: a non-SOL quote never yields Lamports.
4. **MAJOR, provider capability.** Each provider has a list of the methods it serves. A method it does not serve (for example the index methods on Shyft Free) is never sent to it: the read goes to a provider that serves it, or fails with a named error. Rate-limit errors returned as JSON-RPC errors (HTTP 200) count as rate limits (pause, stop count, failover) for the codes each provider documents. VERIFY both from the providers' documentation, with no live calls, and record the sources. Tests for both.
5. **m5.** `meta.err` is required; a missing key is refused.
6. **m6.** The decoder maps the default pubkey quote mint to an explicit native-SOL marker; the default pubkey never leaves the decoder. Test.
7. **m7.** The ESLint rule flags any base58 literal that decodes to 32 bytes outside constants.ts and the fixture paths, covering mints and ACCOUNTS too. Deliberate string building is out of scope (DECISIONS).
8. **m8.** The client checks the response `id` and `jsonrpc: "2.0"`. A mismatch is a protocol error and counts as a failure. Test.
9. **m9.** A 503 with Retry-After also pauses that provider.
10. **m10.** Fee bps that sum to more than 10,000 are refused. A mint with `isInitialized=false` is not decoded as `spl_mint`. Tests.
11. **m11.** `DecodedEvent` carries the inner-instruction ordinal (with the signature), so a duplicate delivery is distinguishable from two fills. If the type lives in `packages/types`, bump its version per the contract rule (supervisor OK given).
12. **m12.** A DECISIONS row covers the process model, citing ARCH. If only one process reads providers, say so, and refuse a second holder of a provider key at start. Otherwise split the 50% budget across processes by config.
